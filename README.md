# Harbin Morning Market

An interactive 3D experience exploring the history, everyday life, and food culture of Harbin's morning markets.

## About the Project

This project explores the transformation of Harbin's morning markets across different historical periods. Through an immersive 3D environment, users can experience the market from a first-person perspective and understand how food, local memories, and everyday social interactions have shaped the city's identity.

## Key Features

- First-person 3D exploration
- Morning market scenes from different historical periods
- Interactive conversations with vendors
- Spatial environmental sounds
- Local food and cultural information
- Immersive storytelling through everyday market experiences

## How to Open the Project

1. Click **Code → Download ZIP** on this GitHub page.
2. Extract the downloaded ZIP file.
3. Open **Unity Hub**.
4. Select **Add project from disk**.
5. Select the extracted project folder.
6. Wait for Unity to import and rebuild the project files.

## Unity Version

Unity 6000.0.80f1

- `Assets` — Scenes, scripts, models, materials, audio and other project assets
- `Packages` — Unity package dependencies
